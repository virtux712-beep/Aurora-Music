Aurora Music 使用说明（0.1.0）
系统要求：Windows 10 / 11（64 位）。程序已内置运行时，无需安装其他组件。

一、选一个包
text
Copy
installer/  Aurora-Music-Setup-0.1.0-x64.exe      安装版（推荐日常使用）
portable/   Aurora-Music-Portable-0.1.0-x64.exe   免安装版（U盘 / 临时电脑）
source/     Aurora-Music-0.1.0-source.zip         源码（不需要就不碰）
docs/       RELEASE-NOTES-0.1.0.md                发布说明
SHA256SUMS.txt                                    完整性校验
安装版：双击 Setup 按提示安装，自动创建快捷方式，不需要管理员权限。
免安装版：把 exe 放任意文件夹双击即可，不写注册表。
两个版本是同一份代码，数据目录相同，可以混用，歌单和历史连续。
首次运行安全提示：程序未做代码签名，Windows 可能弹「已保护你的电脑」，点「更多信息 → 仍要运行」即可，不是包坏了。

校验完整性（可选）：Get-FileHash .\installer\Aurora-Music-Setup-0.1.0-x64.exe -Algorithm SHA256，结果与 SHA256SUMS.txt 对应行一致即可。

卸载：安装版从「设置 → 应用」卸载；免安装版直接删 exe。两种卸载都不删数据，彻底清理需手动删除 %APPDATA%\aurora-music\。

二、第一次打开，按这个顺序
导入本地音乐：把文件或整个文件夹直接拖进窗口任意页面；支持 MP3 / FLAC / WAV / M4A / OGG。
选主题：设置 →「主题中心」，内置五套（星河入梦 / 晚秋拾叶 / 潮汐晨光 / 烟雨江南 / 落日长歌）。
试试沉浸模式：Ctrl+Shift+L 进歌词页，页内有「歌词 / 频谱律动 / 拟真唱片」三种视图，F11 全屏。
三、功能速查
想做什么	去哪里
导入 / 批量管理歌曲	音乐库页，或直接拖拽进窗口
均衡器、输出设备、睡眠定时	设置 → 声音
歌词颜色、偏移校准、桌面歌词	歌词页内 / 设置 → 桌面歌词
主题、沉浸/影院模式、动画档位	设置 → 主题中心
在线音源安装、授权、自检	设置 → 音乐源
缓存查看与清理	设置 → 缓存与数据
备份 / 恢复数据	设置 → 数据与备份
开机自启、托盘	设置 → 系统集成
软件有什么功能、缺什么	设置 → 功能状态（52 条）
快捷键：空格 播放/暂停 · ←/→ 快退/快进 5 秒 · Ctrl+↑/↓ 音量 ±5% · Ctrl+K 或 Ctrl+F 搜索 · Ctrl+Shift+L 歌词页 · F11 全屏 · Ctrl+Shift+A 诊断面板（Aurora Lab）· 媒体键全局有效。

托盘右键菜单：播放/暂停 · 上一首 · 下一首 · 显示/隐藏主窗口 · 开关桌面歌词 · 退出。双击图标恢复窗口。

四、在线音源
两种装法：

脚本音源（.js，洛雪格式）：「音乐源 → 安装音源」选文件，或直接把 .js 拖进窗口。
自定义音源：安装区「新建自定义音源」，填表单即可，不执行任何代码。
每个音源有独立管理页（列表卡片点「管理」）：自检与修复 / 联网授权 / 配置 / 能力与平台 / 错误历史，只作用于这一个音源。

三个常用按钮：

全量自检：换电脑、换网络后用。一次跑遍所有已启用音源，分类为：待授权 / 超时 / 待配置 / 未加载 / 出错 / 正常；待授权的行内直接给「允许」按钮。
自检并自动修复（单音源页）：某音源解析失败时用；只有「主机被拒」会被自动修复，其余如实报告。
允许 <主机>：看到「需要访问某主机，尚未授权」时点它。
首次播放被拦是正常的：很多音源要到取歌时才暴露要访问的主机。默认策略是被拒后自动允许那一台并立即重试（审计记录在音源页）。想改严格模式：音乐源设置里关掉「播放时自动允许」。

安全模式（默认关闭）：打开后未授权主机不再自动放行、拒绝明文 http 接口、新装音源默认禁用。只用 http 接口的音源会因此解析失败，代价写在开关旁。

导入报「这个文件不是脚本文本：它是 ZIP 压缩包」：说明文件本身是坏的（多半是被改名成 .js 的 Word 文档或下载未完成），重新下载源文件即可。

五、数据位置与备份
全部在 %APPDATA%\aurora-music\：aurora.db（曲库索引）、settings.json（设置）、covers/ 与 lyrics/（缓存）、logs/crash.jsonl（崩溃日志，已脱敏）。备份：设置 → 数据与备份导出 JSON；恢复时做版本校验，失败不会覆盖现有数据。

六、性能与功耗
动画档位：关闭 / 节能 / 标准 / 沉浸，低性能设备自动降级；帧率默认跟随显示器，可手填 24–240。
暂停或失焦时背景动画自动冻结、画布降分辨率——暂停时省电是设计行为，恢复播放立即回原速。
想看实际帧率与开销：Ctrl+Shift+A。
七、出问题了怎么办
症状	先试
在线搜不到	音源页「全量自检」；待授权点允许；超时多半是网络
装音源报「ZIP 压缩包」	换源重新下载，文件本身是坏的
歌词不同步	歌词页偏移校准，±100ms 步进实时生效
动画卡	动画档位调低一档；帧率限到 60
想反馈崩溃	附上 %APPDATA%\aurora-music\logs\crash.jsonl 最后几条
八、已知边界
迷你播放器窗口未实现（功能状态卡里唯一缺口）。
批量修改歌曲信息只支持 MP3。
更新检查只提示并打开下载页，不静默安装。
本地 HTTP API 默认关闭；开启后只监听 127.0.0.1，除健康检查外都要 token。
程序未签名，首次运行有 SmartScreen 提示。
