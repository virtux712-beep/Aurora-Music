# Aurora Music

一款免费的 Windows 音乐播放器：本地曲库 + 在线音源，歌词沉浸模式与五套内置主题。

当前版本：**0.1.0** · 系统要求：Windows 10 / 11（64 位），已内置运行时，无需安装其他组件。

安装版与免安装版是同一份代码、共用同一数据目录，可以混用，歌单和历史连续。程序未做代码签名，首次运行如遇 Windows「已保护你的电脑」提示，点「更多信息 → 仍要运行」即可。

## 快速开始

1. **导入本地音乐**：把文件或整个文件夹直接拖进窗口任意页面（MP3 / FLAC / WAV / M4A / OGG）。
2. **选主题**：设置 → 主题中心，内置五套（星河入梦 / 晚秋拾叶 / 潮汐晨光 / 烟雨江南 / 落日长歌）。
3. **试试沉浸模式**：`Ctrl+Shift+L` 进歌词页，页内有「歌词 / 频谱律动 / 拟真唱片」三种视图，`F11` 全屏。

## 主要功能

- **本地音乐库**：拖拽导入、批量管理歌曲
- **在线音源**：脚本音源（.js，洛雪格式）与自定义音源，每个音源独立管理，带全量自检与联网授权
- **歌词**：沉浸歌词页、桌面歌词、偏移校准
- **声音**：均衡器、输出设备、睡眠定时
- **主题与动画**：五套主题、沉浸/影院模式、动画档位可调
- **数据**：备份 / 恢复、缓存管理，全部数据位于 `%APPDATA%\aurora-music\`

- 迷你播放器窗口尚未实现
- 批量修改歌曲信息只支持 MP3
- 本地 HTTP API 默认关闭；开启后只监听 127.0.0.1
